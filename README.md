# Risa Birthday — Website Ulang Tahun ke-17 ♡

Website statis aesthetic untuk ucapan ulang tahun Risa Cahya Cantik.

## Isi project
- `index.html` — struktur halaman
- `style.css` — desain, responsive, animasi
- `script.js` — scroll reveal, confetti, lightbox, tombol wish, ambience
- `assets/` — 4 foto yang digunakan di website

## Upload ke GitHub
1. Buat repository baru di GitHub, misalnya `risa-birthday`.
2. Upload semua isi folder project ini.
3. Pastikan `index.html` ada di root repository.
4. Commit / push.

## Deploy ke Vercel
1. Buka Vercel dan login dengan GitHub.
2. Klik **Add New → Project**.
3. Import repository `risa-birthday`.
4. Framework preset pilih **Other** (atau biarkan Vercel mendeteksi sebagai static site).
5. Build Command: kosongkan.
6. Output Directory: `.`
7. Klik **Deploy**.

Setelah selesai, Vercel akan memberikan URL website.

## Catatan
Website tidak membutuhkan backend atau database. Musik suasana dibuat menggunakan Web Audio API sehingga tidak perlu mengunggah file musik tambahan.
